# Limitations and roadmap

## Current limitations

| Area | What is true now |
|---|---|
| Audience | The reading load and running simulation currently suit ages 12+. There is no validated age study or dedicated kids mode. |
| Language | The experience is mainly English. How to Play includes one short Arabic instruction, but there is no full Arabic localization or language switch. |
| Science | Models are educational shortcuts. Meters are not engineering units; shield is not radiation dose. |
| Space weather | The storm is scripted. No live DONKI provider, forecasting or alert service is connected. |
| Archived record | The stored X1.7 flare entry still says `needs_verification`; it is not a particle measurement. |
| Event consequences | Dust, leak and battery choices change meters immediately, without persistent physical faults or temperatures. |
| Systems | There is no full gas chemistry, water processing, food production, electrical circuit or rover battery model. |
| Crew | The story describes four crew; no individual crew health, dialogue or crew-management system is implemented in the engine. |
| Learning evidence | Four optional questions track responses, not learning gains. Completed-objective concepts do not prove reading or mastery. |
| Reports | Source clicks are untracked. Old saves may lack historical reserve/decision measurements. |
| Saves | One local in-progress save per browser origin; no account, cloud sync or completed-results archive. |
| Timing | Time continues during decisions and learning text unless paused. Faster simulation does not speed up world travel. |
| Performance | WebGL capability and real frame rate matter. Frame-delta capping can slow movement relative to the simulation clock on weak devices. No real-device performance measurements are claimed here. |
| Tests | Function-level campaigns do not replace browser, real-touch, accessibility or real-classroom testing. |

The module list in the engine contains habitat, oxygen, solar, ice, rover, survey, shelter and relay. Do not promise a separately playable greenhouse, shield-repair task or crew conversation just because a broader project vision mentions them.

## Possible next steps — not implemented

1. **Kids Mode for ages 7–12:** simpler wording, guided choices and pausing while reading. Validate with actual learners before claiming suitability.
2. **Arabic localization:** translations, right-to-left layouts and full UI testing, beyond the current short Arabic instruction.
3. **Classroom use:** teacher guidance and optional pre/post assessment. Record real study methods before claiming an educational improvement.
4. **Live NASA data:** an attributed, verified provider with clear timestamps and failure states. Keep historical data, observations and game simulation separate.
5. **Source maintenance:** directly recheck the archived flare and periodically review NASA links and relevance.
6. **Device and accessibility review:** actual phones/tablets, touch reliability, keyboard focus, reading load and low-frame-rate fairness.

These are roadmap items, not permission to change the existing balance, objectives, save format or interface. The current Hard configuration and its tests are documented as implemented, not silently retuned.
