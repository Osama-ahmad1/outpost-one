# AI Usage and Team Contributions
## StarBound – OutpostOne

### 1. AI Usage and Development Tools

This project was developed with the assistance of **Replit Agent**. The team also used **Claude (Anthropic)** as a conversational assistant for:

- Planning the project and organizing development phases.
- Writing prompts and technical instructions for Replit Agent.
- Reviewing development reports and identifying potential issues.
- Explaining code and helping the team understand implementation decisions.
- Drafting technical documentation and presentation content.

The current project includes features developed through this AI-assisted workflow. However, the source code alone cannot establish who wrote each individual line or independently performed every test.

**Important distinction:** The in-game Mission Advisor is not powered by an AI model. It uses predefined programming rules implemented in `flight-guidance.js`.

### 5. Testing and Quality Assurance

The team used both automated and manual testing approaches.

**Automated Testing**

Replit Agent assisted with running automated checks, including:

- Simulation campaigns across Easy, Normal and Hard difficulty levels.
- TypeScript type checking.
- Production build verification.
- Regression checks for simulation behavior and difficulty balancing.

The team reviewed the resulting reports.

**Manual Testing**

Team members also performed manual gameplay testing to examine the actual player experience, identify interaction problems and report issues requiring improvement.

Examples of reported issues included the Objective 8 lock-up, rover minimap positioning and difficulty balancing.

**Testing Limitations**

The following areas were not fully verified:

- Testing on a wide range of real touch-screen devices.
- Performance evaluation across different physical devices.
- The Info Card currently supports desktop use only.

### 7. NASA Scientific Sources and Verification

The team reviewed the scientific references used in the project to strengthen the connection between gameplay and real space science.

The references support the educational concepts represented in the simulation, including space weather, radiation, life-support systems and engineering challenges.

The game clearly distinguishes between:

- Real scientific concepts and NASA references.
- Simplified educational explanations.
- Simulated gameplay data that are not live NASA measurements.

One archived DONKI reference remains explicitly marked as unverified. Reviewing a source does not necessarily mean independently confirming every underlying data point.

### 8. Honest Presentation of AI Usage

The team can describe its approach as follows:

"We used Replit Agent to assist with implementing the game, educational content and software checks. We also used Claude to support planning, technical instructions, code explanations and documentation.

Our team selected the challenge, developed the project concept, directed the development process, reviewed scientific sources, tested the game and made decisions about the final implementation.

We also conducted student evaluation to gather feedback on the educational experience.

The in-game Mission Advisor uses a rule-based system rather than an AI model."

### 9. Project Limitations and Future Improvements

Although the project includes an interactive educational simulation, some areas remain open for future development:

- Expanding compatibility and testing across real mobile and touch-screen devices.
- Conducting more structured educational evaluations with a larger student sample.
- Improving the collection and analysis of student feedback.
- Further strengthening the verification and documentation of scientific references.
- Exploring future integration of reliable live NASA data sources, where technically and scientifically appropriate.

### 10. Transparency Statement

StarBound was developed through collaboration between human team members and AI-assisted development tools.

The AI tools supported implementation, planning and documentation, while the team remained responsible for project direction, scientific review, testing, evaluation and final decisions.

The project is an independent educational simulation. It does not claim NASA endorsement, and its simulated resource values and gameplay outcomes should not be interpreted as actual mission measurements.
