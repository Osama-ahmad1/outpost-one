# OUTPOST ONE - Lunar Survival

Educational lunar outpost game by Team StarBound (NASA Space Apps Challenge 2026).

**Challenge:** Build a Junior Astronaut Mission Trainer.

- **Play:** https://outpost-one-lunar-survival.replit.app/
- **Documentation:** See the `/docs` folder, starting with `docs/README.md`.
- **Note:** Educational simulation, not live NASA data. All game values are simplified.
- **AI use:** Built with Replit Agent; Claude was used for planning, prompts and documentation. See `docs/08-ai-usage.md`.
